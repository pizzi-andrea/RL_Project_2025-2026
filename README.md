# RL_Project_2025-2026


## Investigating advanced model-based reinforcement learning algorithms in the VizDoom environment.

In our project we aim to test a new model-based reinforcement learning method on a
complex environment such as the one offered by the VizDoom platform. The main challenges proposed by the proposed environment are:

1. High reward sparsity
2. High variability in the environment's possibilities (map, character and reward layout)
3. Partial knowledge due to purely perceptual information about the environment
(first-person visual)
